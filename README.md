## О проекте

Универсальный сборщик, для компонентов srv_ стандарта (
см. [критерии](#критерии-исходного-кода-устанавливаемых-сервисов-srv-стандарт)). Загружает все необходимые репозитории
на машине
клиента, не требуется python, git - установщик скачает временные portable python и git, и удалит их сразу после
завершения установки. Предназначен для развертывания desktop приложений без дополнительных зависимостей (например для
клиента не программиста, который врядли захочет ставить docker, которому нужна максимальная простота установки).

## Критерии исходного кода устанавливаемых сервисов (srv стандарт)

### В сервисе должны присутствовать файлы:

- cli.py - ui интерфейс сервиса, имеет команду `build -oe` - сборка .exe/bin ("python cli.py build -oe").
- start.py - скрипт разворачивания сервиса, скачиваются uv зависимости, базовые модели.
- LICENSE - лицензия
- README.md - описание компонента

### В сервисе должна присутствовать директория:

- resources - с необходимыми для сервиса файлами, например модели llm.

**В репозиториях Mike2024New, репозитории соответствующие этим критериям будут отмечаться преффиксом `srv_`, например
srv_llm_offline**

## Быстрый старт

### 1.Создание конфигурационного файла:

Рядом с файлом installer.exe положить installer_settings.json, в котором прописать:

- **app_repo_name** - название главного сервиса (обычно с app_).
- **repositories_url** - загружаемые репозитории (
  соответствующие [критериям](#критерии-исходного-кода-устанавливаемых-сервисов-srv-стандарт) ), а также ведущее
  приложение app_.
- **ensure_python_url** - ссылка на python portable (уже прописана по умолчанию на сборки standalone).
- **ensure_git_url** - ссылка на git portable (уже прописана по умолчанию).

Пример:

```json
{
  "app_repo_name": "app_ai_assistant",
  "repositories_url": [
    "https://github.com/Mike2024New/srv_llm",
    "https://github.com/Mike2024New/srv_tts_silero",
    "https://github.com/Mike2024New/srv_stt_vosk",
    "https://github.com/Mike2024New/app_ai_assistant"
  ],
  "ensure_python_url": "https://github.com/astral-sh/python-build-standalone/releases/download/20260825/cpython-3.12.14+20260825-x86_64-pc-windows-msvc-install_only.tar.gz",
  "ensure_git_url": "https://github.com/git-for-windows/git/releases/download/v2.54.0.windows.1/MinGit-2.54.0-64-bit.zip"
}
```

### 2.Запуск:

Нажать два раза по иконке installer.exe, либо через командную строку в текущей папке `installer.exe`. Начнется установка
и сборка компонентов. Появится окно

## Как это работает

Скачивает portable Python и Git во временную папку, клонирует указанные репозитории, запускает в них start.py (сборка),
собирает .exe через cli.py build -oe, копирует результат в целевую папку, удаляет временные файлы.
